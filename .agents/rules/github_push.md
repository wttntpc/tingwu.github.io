# GitHub Push Rule

Whenever you make changes to files in this repository (HTML, CSS, JS, Markdown), ALWAYS remember to:
1. Run `git add .`
2. Run `git commit -m "<descriptive message>"`
3. Run `git push`

This ensures that the user can immediately see the changes on their live GitHub Pages site. Do this automatically at the end of every task or set of changes without needing the user to explicitly remind you.
