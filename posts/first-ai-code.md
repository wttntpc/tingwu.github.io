做研究時，常有許多重複但不能出錯的工作，例如整理欄位、處理缺漏資料、檢查格式和畫圖。AI 可以協助我先建立程式草稿，讓我把更多時間放在研究問題本身。

## 我通常怎麼使用 AI？

1. 先說清楚資料長什麼樣，以及我想解決什麼問題。
2. 請 AI 提供一小段可以檢查的程式，而不是一次完成所有分析。
3. 用已知答案或少量資料測試結果。
4. 確認正確後，再套用到完整資料。

AI 也很適合協助解讀錯誤訊息，或介紹不熟悉的工具。但它給的程式不一定正確，也不知道研究設計的全部背景，所以不能直接照單全收。

## 最重要的是研究者仍要負責

使用 AI 後，我仍會檢查原始資料、統計方法和輸出結果，也不會把含有個人身分或機密資訊的資料直接交給未經核准的服務。

> 對我而言，AI 是加快討論與試作的助手；最後的判斷、驗證與研究倫理，仍由研究者負責。

在資料分析與研究過程中，我經常使用 Python 或 R 處理實驗資料。生成式 AI 可以協助建立程式雛形、解釋錯誤訊息與比較不同實作方式，但必須放在可驗證、可重現的工作流程中使用。

## 一個簡單的資料清理範例

```python
import pandas as pd

def clean_data(file_path):
    df = pd.read_csv(file_path)
    numeric = df.select_dtypes(include="number").columns
    df[numeric] = df[numeric].fillna(df[numeric].mean())
    return df.drop_duplicates()

cleaned_data = clean_data("experiment_results.csv")
print(cleaned_data.head())
```

這段程式可以作為教學範例，但不應在不了解資料生成機制時直接套用。例如，以平均數填補缺失值可能低估變異，刪除重複列也必須先定義「重複」在研究情境中的意義。正式分析前，應檢查缺失型態、變項尺度與受試者識別方式。

## 把 AI 納入可重現流程

我會將 AI 產出的程式視為待驗證的草稿，並透過以下步驟降低錯誤：

1. **定義輸入與預期輸出**：先建立資料字典及可判斷對錯的測試案例。
2. **逐段執行與檢查**：檢查資料筆數、欄位型態、缺失值和極端值是否符合預期。
3. **保留分析來源**：使用版本控制記錄程式與修改原因，避免只留下最終輸出。
4. **驗證統計假設**：確認模型選擇、排除標準及多重比較處理符合研究問題。
5. **保護研究資料**：依研究倫理、知情同意及機構規範處理個資與敏感資料。

AI 不取代研究者的判斷。它能提升探索與除錯效率，但資料品質、方法選擇、結果解釋及責任歸屬，仍必須由研究者掌握。若要公開分析，還應記錄軟體版本、相依套件與必要的隨機種子，使其他人能重現主要結果。
