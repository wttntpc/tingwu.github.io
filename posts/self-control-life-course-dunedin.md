# 趁年輕累積什麼？一項追蹤 30 年的研究，談「自我控制」

「趁年輕多累積一些東西」，聽起來是老生常談。但到底要累積什麼？有一項研究追蹤了一整個世代的孩子，從出生到 32 歲，發現童年時的<strong>自我控制</strong>能力，和三十年後的健康、財務與犯罪紀錄有關，而且是一條連續的「梯度」，不是只有最差的那一群才受影響。這篇用這項研究，談談「能力」這種可以累積的東西。

> 這是科普整理，不是人生建議或醫療、心理諮商建議。論文談的是群體層級的統計關聯，不能用來預測或評價任何一個人。

## 研究怎麼做的

研究者追蹤紐西蘭但尼丁市在 1972–1973 年出生的 1,037 位孩子，一路到 32 歲，**96% 的人還留在研究裡**，連表現不好的人也沒有流失（Moffitt et al., 2011）。

- <strong>自我控制怎麼量？</strong>3 到 11 歲之間，由研究人員、老師、父母和孩子自己，用 9 項指標（例如衝動、注意力不集中、缺乏毅力、攻擊行為）評分，合成一個分數。這是對日常行為的評分，不是在實驗室做的抑制作業。
- <strong>32 歲時看什麼？</strong>身體檢查與抽血（代謝異常、氣流受限、牙周病、性傳染病、發炎指標），物質依賴的臨床訪談，收入、儲蓄與理財困難，以及法院的犯罪紀錄。
- <strong>怎麼排除其他解釋？</strong>統計上控制了家庭社經地位與智商；另外在一個英國雙胞胎世代（509 對同性的異卵雙胞胎）比較同一個家裡的兄弟姊妹。

## 發現了什麼

童年的自我控制預測了 32 歲時的：

- **健康**：身體健康問題與物質依賴。但<strong>對憂鬱沒有預測力</strong>。
- **財富**：較低的社經地位與收入、較不會理財與儲蓄、較多財務困難，以及孩子由單親撫養的機率。
- **安全**：犯罪被定罪的機率。

最直觀的是把人口分成五等份，比較自我控制最高與最低的兩端：

| 32 歲時 | 自我控制最高的 1/5 | 最低的 1/5 |
|---|---|---|
| 有多項健康問題 | 11% | 27% |
| 多種物質依賴 | 3% | 10% |
| 年收入低於 2 萬紐幣 | 10% | 32% |
| 孩子由單親撫養（已有孩子者中） | 26% | 58% |
| 有犯罪定罪紀錄 | 13% | 43% |

而且這是一條<strong>梯度</strong>：自我控制每高一點，結果就好一點，不是只有最低的那一群才不利。拿掉最差的五分之一、拿掉有注意力不足過動症診斷的孩子，結果仍然成立。

## 「陷阱」：中間那一段發生了什麼

自我控制較低的孩子，在青少年時期比較容易踩進幾個「陷阱」：15 歲前開始抽菸、沒拿到任何學歷就離開學校、未規劃的青少年生育。這些陷阱解釋了一部分的長期差異，例如物質依賴的 63%、單親撫養的 61%，但不是全部；即使沒踩進這些陷阱，童年自我控制仍然預測了後來的結果。

## 自我控制可以改變嗎？

這項研究沒有做介入，但有一個線索：有些孩子從童年到成年早期，自我控制在群體中的排名上升了，這些人到 32 歲時的結果比較好，即使控制了他們童年時的起點。作者自己提醒：自然發生的改變，不一定等於介入帶來的改變。

## 要小心的地方

- <strong>這是觀察性研究。</strong>作者明說設計是觀察與相關，不能證明因果。自我控制和家庭社經地位（*r* = .25）、智商（*r* = .44）都有關，雖然統計上控制了它們，仍無法排除其他因素。
- <strong>效果有大有小。</strong>自我控制的預測力，和智商、社經地位大致相當；加入控制後，部分效果會縮小，有些甚至不顯著（例如憂鬱）。
- <strong>這是群體統計，不是命運。</strong>同一個人的自我控制會變，結果也有很大的個別差異。
- <strong>世代與地區。</strong>研究對象出生在 1970 年代的紐西蘭，今天不同環境下是否相同，要看其他研究。
- <strong>這篇文章把它轉成對年輕人的啟發，是我的延伸，不是論文直接測試的。</strong>論文測的是兒童，作者談的也主要是政策。

## 趁年輕，可以累積什麼？

在論文證據的範圍內，比較站得住腳的是這三點：

1. <strong>把自我控制當成一種可以練的能力。</strong>包含延遲滿足、控制衝動、調節情緒的表達、堅持與規劃。論文顯示它與長期結果有關，也有跡象顯示它會改變。
2. <strong>盡量避開會「關上機會之門」的早期決定。</strong>研究裡的陷阱（早早開始抽菸、沒完成基本學歷、未規劃的生育）是自我控制影響長期結果的重要路徑之一。
3. <strong>讓好的選擇變成預設。</strong>作者在討論政策時指出，自動加入的方案（例如薪資自動提撥儲蓄）對自我控制較低的人特別有幫助。把它用在個人，例如自動扣款儲蓄，是我的解讀，論文沒有測試個人層級的做法。

# 童年自我控制的梯度與成年的健康、財富與公共安全：Moffitt 等人（2011）導讀

本文依據該文獻的全文整理（PMC 全文，細節已回到全文核對；全文頁面無頁碼，故以章節與表格標示）；書目與 DOI 已核對。補充材料（SI Appendix）未讀。

## 研究問題

政策制定者考慮推動以自我控制為目標的大型方案，但自我控制對全人口的健康、財富與公共安全是否重要尚不清楚。Moffitt 等人（2011）以但尼丁多領域健康與發展研究（Dunedin Multidisciplinary Health and Development Study）檢驗四個假設：（1）童年自我控制對結果的預測是否沿整條梯度成立；（2）自我控制排名上升者的結果是否較好；（3）青少年期的錯誤是否中介其影響；（4）學齡前的自我控制是否已可預測成年結果（引言）。

## 設計與測量

- **世代**：1972–1973 年於紐西蘭但尼丁出生的 1,037 位兒童，追蹤至 32 歲，留存率 96%。
- <strong>自我控制（3–11 歲）</strong>：9 項測量（3、5 歲的觀察者對失控行為的評分；5、7、9、11 歲的父母、老師與自評的衝動性攻擊、過動、缺乏毅力、注意力不足、衝動），主成分分析後平均為單一複合分數（內部一致性 α = .86）。女孩平均較高（*t* = 8.39），但各結果的關聯在性別間相似，故合併分析並控制性別。
- **共變量**：自我控制與家庭社經地位（*r* = .25）、智商（*r* = .44）相關，因此在模型 2 控制兩者。
- **32 歲結果**：身體健康指數（代謝異常含過重、氣流受限、牙周病、性傳染病、C 反應蛋白；43% 無、37% 一項、20% 兩項以上）；DSM-IV 臨床訪談的憂鬱與物質依賴；知情者報告；社經地位、收入、單親撫養（僅 47% 已有子女者）、財務規劃、財務困難；法院定罪紀錄（24% 於 32 歲前被定罪）。
- **手足比較**：英國 E-Risk 雙胞胎世代（2,232 位）中 509 對同性異卵雙胞胎，5 歲時以相同的觀察量表評分，結果在 12 歲；使用手足固定效應模型。

## 結果

<strong>主要結果（表 1，模型 2，控制社經地位與智商）</strong>

| 結果 | 低自我控制的係數 | 備註 |
|---|---|---|
| 身體健康指數 | IRR = 1.111（1.020–1.209），*p* = .016 | |
| 復發性憂鬱 | OR = 1.099（0.849–1.352），*p* = .369 | 不顯著 |
| 物質依賴指數 | IRR = 1.186（1.038–1.355），*p* = .012 | 知情者報告亦一致 |
| 單親撫養 | OR = 1.479（1.147–1.908），*p* = .003 | |
| 財務困難 | β = 0.156，*p* < .001 | |
| 犯罪定罪 | OR = 1.714（1.425–2.063），*p* < .001 | |

- **梯度**：移除 61 位 ADHD 診斷者、移除最低五分位、同時移除最高與最低五分位後，線性關聯仍在。
- **極端組比較**：最高對最低五分位的比率，多項健康問題 11% 對 27%、多種物質依賴 3% 對 10%、年收入低於 2 萬紐幣 10% 對 32%、單親撫養 26% 對 58%、定罪 13% 對 43%。
- **排名改變**：童年自我控制與成年早期人格量表的自我控制相關 *r* = .30；自我控制排名上升者在 32 歲有較好的結果，即使控制起點。
- **青少年陷阱**：低自我控制者更常在 15 歲前開始抽菸（OR = 1.69，95% CI [1.45, 1.96]）、無任何學歷離校（OR = 2.28 [1.92, 2.72]）與未規劃的青少年生育（OR = 1.79 [1.40, 2.29]）。控制陷阱後，自我控制的效果衰減：健康 32%、物質依賴 63%、社經地位 35%、收入 29%、單親撫養 61%、財務規劃 35%、財務困難 47%、犯罪 42%；直接效應多數仍顯著。
- <strong>學齡前（3–5 歲）</strong>：觀察量表仍預測 32 歲的健康、財富與定罪，效果量偏小。
- <strong>手足比較（12 歲結果）</strong>：5 歲時自我控制較差的手足，較可能在 12 歲開始抽菸（*B* = 0.07，*p* < .03）、學業較差（*B* = −0.13，*p* < .001）、有反社會行為（*B* = 0.09，*p* = .007），控制手足的智商差異後仍顯著。

## 如何解讀

作者的結論是：自我控制的個別差異在幼年即存在，並能預測三十年的多項結果，且可與智商、社經地位和家庭環境分開，因此可作為政策目標；時機上與「兩段式」介入相容（幼年與青少年）。以下限制影響解讀：

1. **觀察性、相關性設計**：作者自述如此。手足比較與統計控制降低了部分混淆，但不能排除遺傳、未測量的家庭與環境因素。
2. **建構的複合性**：自我控制是涵蓋衝動、注意、毅力與攻擊的「傘狀」構念，由行為評分而來，與實驗室的抑制作業（例如停止訊號作業）屬不同層次的測量。
3. **效果量**：與智商、社經地位的預測力相當，但加入控制後多項係數縮小；憂鬱無預測力；健康指數的效果在模型 2 為 IRR 1.11。
4. **改變的證據是自然史**：作者提醒，自然發生的改變不等於介入引起的改變；研究沒有介入條件。
5. **陷阱的中介是部分的**：衰減介於 29–63%，直接效應仍在；陷阱的選擇「並不詳盡」。
6. **世代與地區**：1970 年代出生的紐西蘭世代；E-Risk 世代只追蹤到 12 歲。
7. **本文的延伸**：把結果轉為對年輕人的建議（以及自動儲蓄等個人層級做法）是推論，原文討論的是政策與兒童。

## 與本站研究主題的連結

論文把自我控制連到神經科學中額葉支持的<strong>執行功能</strong>（引言），這與本站的停止訊號作業、Go/No-Go 作業所測的「抑制控制」相關；但本研究的自我控制是以日常行為評分合成，與實驗室的作業表現是不同的測量，兩者的關係不能直接類推。情緒調節也被列在自我控制的範疇內（引言提到的「調節情緒的表達」）。相關背景見[停止訊號作業的背景](#/post/emotional-selective-stop-signal-task)與[情緒不是「突然出現」的](#/post/emotion-popular-science-primer)。
