# 認知神經科學學習地圖：從大腦、認知到情緒

認知神經科學不是背誦「某個腦區負責某個功能」，而是學會用多種證據回答：大腦如何產生知覺、注意、記憶、決策、情緒與行為？腦區通常以網路合作，同一個行為也可能包含多個歷程，因此要同時理解大腦、心理功能、測量方法與推論限制。

## 建議的五級路徑

1. **100 基礎**：神經元、突觸、神經傳導物質、中樞與周邊神經系統、主要腦葉與皮質下結構。
2. **200 機制**：感覺與知覺、注意、工作記憶、長期記憶、執行功能、動作控制，以及情緒的生成與調節。
3. **300 量測**：行為作業、病灶研究、EEG／ERP、fMRI、眼動與周邊生理訊號各自能回答什麼。
4. **400 分析**：反應時間與正確率、ERP、頻譜、腦影像統計，以及多重比較與資料品質。
5. **500 整合**：把運動、老化、情緒、EEG、HRV 與認知表現放進同一個可檢驗的研究模型。

## 學習、複習與深化

- **學習**：每次先回答「這個構念是什麼、如何操作化、用什麼方法測量」。
- **複習**：不看筆記畫出腦區—網路—功能—測量的關係，再用自己的話解釋。
- **深化**：比較兩個理論能否做出不同預測，並找出研究設計無法排除的替代解釋。

第一輪建議依序學「大腦基本結構 → 注意與記憶 → 執行功能 → 情緒與認知互動 → EEG 與實驗設計」。

> 這是學習入口，不是腦區功能對照表。看到「某腦區亮起」時，仍需考慮作業設計、比較條件、時間尺度與反向推論。

# 認知神經科學學習地圖：從大腦、認知到情緒

## 核心範圍

這條主線以「神經實作—心理構念—測量模型—統計推論」四層連結大腦、認知與情緒。認知神經科學由認知心理學、神經心理學及腦造影等傳統交會而成；它能將心理歷程拆解後連回神經系統，但不能僅憑活化位置證明單一心理功能。

| 層級 | 核心模組 | 完成標準 |
|---|---|---|
| 100 基礎 | 神經元、突觸、神經解剖、腦網路 | 能由細胞到系統解釋訊息如何傳遞 |
| 200 機制 | 知覺、注意、記憶、執行功能、動作、情緒 | 能區分構念並提出可觀察預測 |
| 300 量測 | 病灶、EEG／ERP、fMRI、TMS、行為與生理量測 | 能依時間、空間與因果問題選方法 |
| 400 分析 | 操作化、訊號處理、GLM／混合模型、多重比較 | 能說明資料到結論的每一個轉換 |
| 500 整合 | 運動、老化、情緒與腦—身體調節 | 能建立 DAG／理論模型並設計驗證研究 |

## 情緒應放在哪裡？

情緒不是認知的附錄。建議並行學習情緒生成、喚醒與效價、內感受、威脅與獎賞、情緒記憶及情緒調節，再檢視它們如何改變注意、抑制控制與決策。不同理論對皮質與皮質下結構的必要性仍有爭議，筆記應區分「觀察結果」「理論解釋」和「尚待檢驗的主張」。

## 情緒系列的寫作與證據規格

每日文章採「定義—理論—機制—測量—限制—應用」六段式。白話版先用生活情境建立直覺；專業版至少比較兩種可能解釋，並避免把主觀感受、行為表現、周邊生理反應與神經訊號當成可以互相取代的情緒指標。

每一項重要主張應標示其證據層級：

- **概念或理論主張**：說明是哪一套理論的定義，不寫成全領域共識。
- **關聯證據**：區分相關、預測與因果，不從 fMRI 活化直接反推特定情緒。
- **機制證據**：優先檢查病灶、刺激、藥理、縱貫或多方法研究是否支持必要性與時間順序。
- **應用證據**：運動、老化或情緒調節的效果應回到研究族群、介入劑量、結果指標與不確定性。

建議把 NotebookLM 作為來源探索與跨文獻問答工具，但正式文章仍須開啟原始論文核對作者、研究設計、結果與限制。NotebookLM 的摘要不能取代原文驗證。

## 證據與複習規則

每個主題保留一張概念卡（定義、機制、測量、混淆因子、代表證據）與一張方法卡（訊號來源、解析度、前處理、模型、限制）。完成一級後，以無提示回憶、概念圖與研究批判各做一次檢核；能提出可反駁預測，才算進入下一級。
