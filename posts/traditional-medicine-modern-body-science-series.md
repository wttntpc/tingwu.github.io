# 傳統醫學與現代身體科學：跨領域科普系列

> **系列定位｜持續更新中** 這是我以「對中醫與身體科學有興趣的研究生」身分進行的跨領域學習紀錄。我會從原始研究、系統性回顧與官方資料出發，練習分辨傳統理論、可能的生理機制與臨床效果。內容不代表中醫、針灸或醫療專業資格，也不能取代診斷與治療。

中醫談經絡、氣血與整體平衡；現代身體科學則常用解剖、生理、神經、筋膜、心理與臨床結果描述人體。兩套語言有時指向相近的身體經驗，卻不能因為「聽起來相似」就直接畫上等號。這個系列的目的不是證明哪一套理論一定正確，而是逐步問清楚：**它在描述什麼、研究實際測量了什麼、證據能支持到哪裡？**

## 先從五篇開始

| 順序 | 規劃文章 | 主要問題 | 閱讀重點 |
|---|---|---|---|
| 01 | **中醫與現代解剖在談同一個身體嗎？** | 經絡、穴位、筋膜、神經與肌肉鏈可以直接對應嗎？ | 區分「概念類比」與「解剖證據」 |
| 02 | **針灸能幫助運動傷害恢復嗎？** | 疼痛變少是否等於組織已癒合、功能已恢復？ | 分開評估疼痛、活動度、力量、功能與重返運動 |
| 03 | **太極與氣功如何影響認知與情緒？** | 效果可能來自動作、呼吸、注意、期待，還是社交互動？ | 理解多成分介入與對照組設計 |
| 04 | **美顏針灸真的能改善皮膚與皺紋嗎？** | 照片看起來不同，是否代表有可靠效果？ | 觀察盲法、光線、評分者、追蹤期與不良反應 |
| 05 | **如何閱讀中醫研究而不落入「有效／無效」二分法？** | 一篇正向研究可以證明療效嗎？ | 研究設計、偏差、效果量、證據確定性與安全性 |

這五篇累積完成後，我會再依讀者需求延伸到中藥與運動恢復、睡眠與自律神經、疼痛神經科學、情緒調節，以及老化與認知健康。累積六至十篇後，再評估是否建立獨立的學習地圖。

## 每篇文章怎麼讀？

每篇文章都會把內容拆成三層，避免把不同性質的主張混在一起：

1. **傳統理論層**：典籍或中醫理論如何描述這個問題？這是理論背景，不等於已被現代實驗直接證實。
2. **現代機制層**：研究者提出哪些解剖、生理、神經、心理或社會機制？這些通常是可檢驗的假說，不一定已被完整證明。
3. **臨床結果層**：研究是否真的觀察到疼痛、功能、情緒、認知或生活品質的改變？效果有多大、維持多久、是否安全？

文章中的結論會使用下列標示：

- **較有支持**：有多篇品質尚可且方向一致的研究，但仍須留意適用族群與效果大小。
- **初步證據**：有可參考的研究訊號，但樣本小、偏差風險高或尚未重複驗證。
- **機制假說**：具有生理合理性或實驗線索，尚不能直接推論臨床有效。
- **證據不足**：目前無法下結論，不等同於已證明「一定沒有效」。

## 論文裡的圖，可以直接放到網站嗎？

不一定。**能免費閱讀，不代表圖片可以自由重製。** 即使文章收錄於 PubMed Central，也要查看該篇文章的「Copyright and License information」以及每張圖的圖說；第三方圖片可能另有權利限制。

我會依照以下順序處理：

1. 先確認文章與該張圖的授權，不只看期刊是否開放閱讀。
2. 優先使用 **CC BY、CC0 或公有領域**的圖片。
3. 圖說保留作者、年份、論文題名、期刊、圖號、DOI／網址、授權連結與修改說明。
4. 若是 CC BY 圖片，可以在標示來源後重製或改編；若含 NC、ND 或 SA 條款，則另外遵守非商業、禁止改作或相同方式分享等限制。
5. 若找不到明確的重製授權，不把論文截圖上傳到 GitHub；改用原圖連結、向權利人申請，或依已查核的事實與數據重新設計一張具有新表達方式的解說圖。
6. 可辨識患者或受試者的臨床照片，必須另外確認肖像、同意與出版權，不因論文公開就直接使用。

## 我的學習與寫作流程

每一篇會依序完成：提出問題 → 搜尋原始研究與系統性回顧 → 確認研究族群與介入 → 評估偏差與安全性 → 解讀效果量 → 查核圖片授權 → 撰寫白話版與專業版 → 保留原始來源。

我也會特別區分「有統計顯著差異」與「差異大到具有臨床意義」。對運動傷害而言，疼痛下降不一定代表可以安全重返運動；對認知與情緒而言，短期量表改善也不一定表示長期神經功能已改變。

> **安全提醒**：針灸、中藥、推拿與其他介入都有適應症、禁忌與可能風險。若涉及疾病、用藥、懷孕、出血風險或持續疼痛，應尋求合格醫療專業人員評估，不應只依網站文章自行處置。

# 傳統醫學與現代身體科學：系列研究與編輯框架

## 系列定位與範圍

本系列是研究生的跨領域科學傳播與方法學學習紀錄，不是臨床指引，也不代表作者具備中醫、針灸或醫療執業資格。系列以傳統醫學相關問題為起點，連結解剖學、運動傷害防護、神經科學、心理學、皮膚科學與循證醫學，但不預設傳統概念與現代生物醫學構造存在一對一對應。

每篇文章須分離三種證據命題：

1. **理論命題**：某概念在傳統理論中的定義、歷史與內部一致性。
2. **機制命題**：可被現代方法檢驗的生理、神經、心理或社會機制。
3. **效果命題**：介入對症狀、功能、生活品質、不良事件或其他臨床結局的因果效果。

機制證據不能替代臨床效果證據；臨床效果存在，也不會自動證實某一套理論機制。觀察到相關性，更不能直接推論因果。

## 五篇首發規劃

### 01｜經絡、穴位、筋膜、神經與肌肉鏈

比較不同系統的概念邊界與測量方式，說明「位置相近」「功能描述相似」與「結構同一」是三種不同主張。文章會檢視解剖研究的取樣方式、定位誤差、研究者自由度，以及事後對應的風險。

### 02｜針灸與運動傷害恢復

建立分層結局：疼痛強度、關節活動度、肌力、動作品質、患者報告功能、復發、重返運動時間與不良事件。研究若只改善疼痛，不應延伸解讀為組織癒合或競技能力恢復。

### 03｜太極、氣功、認知與情緒

把介入拆成低至中強度活動、呼吸調節、動作學習、持續注意、團體互動與期待效應，並比較等待名單、健康教育、一般運動與主動對照組。不同對照條件回答的是不同因果問題。

### 04｜美顏針灸與皮膚結果

優先檢視客觀量測、盲法評分、標準化攝影、光線與姿勢、受試者期待、追蹤時間、最小臨床重要差異與不良反應。前後照片不能單獨取代合適的對照與評估程序。

### 05｜超越「有效／無效」的研究判讀

建立適用於傳統醫學研究的閱讀框架：研究問題、PICO、隨機化與分派隱藏、盲法、對照介入、失訪、選擇性報告、效果量與不確定性、異質性、證據確定性、利益衝突與安全性。

## 統一的證據紀錄表

| 欄位 | 每篇文章必須回答的問題 |
|---|---|
| 研究問題 | 研究要估計的是機制、相關性、診斷效度，還是介入效果？ |
| 理論主張 | 傳統理論原本如何定義？是否避免用現代術語重新包裝？ |
| 生物醫學假說 | 假說是否可檢驗？測量能否直接支持它？ |
| 研究設計 | RCT、觀察研究、機制實驗、病例系列或系統性回顧？ |
| 對照條件 | 自然病程、安慰效應、照護時間與共同介入是否被控制？ |
| 主要結果 | 量表、客觀功能、臨床事件或替代指標？ |
| 效果解讀 | 同時呈現效果量、信賴區間／可信區間與臨床重要性。 |
| 偏差與適用性 | 盲法、遺失資料、選擇性報告、族群與場域限制。 |
| 安全性 | 不良事件如何定義、蒐集與報告？ |

每張論文圖片在發布前建立來源紀錄：文章題名、作者、年份、期刊、DOI／永久網址、原始圖號、權利人、授權版本、授權網址、是否含第三方內容、本站所做修改及查核日期。

## 發布前檢核

- 身分與資格表述清楚，未暗示臨床執業資格。
- 理論、機制與臨床效果分開陳述。
- 關鍵主張可追溯到原始研究或高品質綜整證據。
- 不用單一顯著結果做確定性結論。
- 圖片授權逐張查核，圖說包含完整來源與修改資訊。
- 報告限制、不良事件與適用範圍。
