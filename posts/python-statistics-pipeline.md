拿到研究資料後，最常見的問題是：「我應該按哪一個統計檢定？」但真正可靠的分析，並不是從選單裡挑一個名稱，而是先把研究問題、資料結構與判斷規則說清楚。

## 第一步不是算 p 值，而是認識研究設計

先確認資料在比較什麼：

- 不同受試者之間的兩組比較，例如運動組與控制組。
- 同一批受試者的前後測比較。
- 同時包含組別與時間的混合設計。
- 變項之間的相關或預測關係。

同一位受試者的前後測彼此有關，不能當成兩群互不相干的人。若一開始認錯資料結構，後面的程式即使順利執行，答案仍可能不合理。

## 先檢查資料，再開始分析

我的流程會先確認必要欄位是否存在、數值欄位是否真的是數字、受試者代碼有沒有缺漏，以及同一位受試者在同一時間點是否出現重複紀錄。

我偏好讓程式遇到問題時明確停止，而不是默默跳過錯誤。因為「成功輸出表格」不代表資料處理正確。

## p 值不是唯一答案

p 值可以協助判斷觀察結果與虛無假設是否相容，但不能告訴我們效果有多大。因此，分析還要報告效果量、信賴區間、實際樣本數與描述統計。

圖表也不只是裝飾。呈現每位受試者的前後變化，通常比只有兩根平均數長條圖更容易看出個體差異與異常資料。

> 一套好的統計 Pipeline，不是替研究者自動做決定，而是讓每個決定都能被看見、檢查與重現。

可重現的統計分析應由研究設計驅動，而不是由單一檢定結果觸發一連串自動選擇。我的 Pipeline 將流程拆成資料驗證、描述統計、模型假設、主要分析、效果量、視覺化與報告，並要求每一步保留可稽核的輸出。

## 以設計結構定義分析

開始前先指定依變項、組間因子、組內因子及受試者識別碼：

```python
DV = "score"
BETWEEN = "group"          # 沒有組間因子時設為 None
WITHIN = "time"            # 沒有重複量測時設為 None
SUBJECT = "participant_id"
ALPHA = 0.05
PADJUST = "holm"
```

兩組獨立樣本、配對測量、單因子多組比較與組別 × 時間混合設計，具有不同的獨立性結構。尤其在重複量測資料中，受試者識別碼不是附加資訊，而是模型辨認相依觀測的核心。

## 輸入驗證應該明確失敗

正式分析前應檢查：必要欄位、資料型別、缺值、類別順序、每組樣本數，以及 `SUBJECT × WITHIN` 是否有未定義的重複資料。若存在重複紀錄，應先決定平均、取中位數或保留試驗層級模型，不能交由 `pivot` 隱性處理。

類別水準也應明確排序，例如將 control 設為參考組、pre 排在 post 之前，避免資料出現順序改變係數方向。

## 檢查正確的常態性對象

常態性檢查並非固定套用在原始依變項：

| 分析 | 主要檢查對象 |
|---|---|
| 獨立樣本比較／ANOVA | 組別內分布與模型殘差 |
| 配對 t 檢定 | 每位受試者的配對差值 |
| 重複量測 ANOVA／LMM | 模型殘差與極端個案 |
| 線性回歸 | 回歸殘差 |

常態性檢定的 `p > .05` 只代表目前沒有足夠證據拒絕常態假設，不能寫成「證明資料為常態」。方法選擇應同時考量研究設計、資料尺度、獨立性、離群值與 QQ plot。

Levene 檢定則針對獨立組別的變異數同質性。變異數不同質時，兩組比較可考慮 Welch t 檢定，多組單因子設計可使用 Welch ANOVA 與 Games–Howell；這不等同於資料非常態，也不是任意刪除離群值的理由。

## 同時報告效果大小與不確定性

p 值回答資料與虛無假設的相容程度，效果量則描述差異大小。ANOVA 報告必須區分 η²、partial η² 與 ω²，因為它們的分母和解讀不同，不能只寫一個未標示種類的 eta squared。

一般而言，分析輸出至少應包含樣本數、估計值、95% 信賴區間、檢定統計量、校正後 p 值及預先指定的效果量。所謂小、中、大效果的門檻只能作為參考，不能取代研究領域中的實質重要性。

## 讓圖表保留個體資訊

獨立組別可同時呈現原始資料與分布；重複量測則適合畫出每位受試者的軌跡，再疊加群體估計。這能讓讀者看見平均值背後是否存在方向不一致、極端個案或樣本流失。

當資料包含不平衡測量、遺漏時間點或複雜階層結構時，線性混合效果模型可能比傳統重複量測 ANOVA 更合適，但模型選擇仍應由研究問題與資料生成機制決定。Pipeline 的價值不在自動化所有判斷，而在讓分析設定、排除規則、軟體版本與輸出都能被重現。
