<!-- SIMPLE -->

兩組資料的平均數完全一樣，不代表兩組資料長得一樣。可能一組非常集中，另一組有明顯離群值；也可能平均差異只由一個人拉動。若只放一張長條圖，這些資訊都會消失。

> 本文是「數據整理與統計分析」系列第 2 篇。圖表不是統計結果的裝飾，而是讓讀者看見資料分布、研究設計與不確定性的分析工具。

## 先問問題，再選圖

| 想回答的問題 | 建議起點 | 容易出錯的圖 |
|---|---|---|
| 一個連續變項如何分布？ | 點圖、直方圖、密度圖 | 只顯示平均數的長條圖 |
| 兩組獨立樣本有何差異？ | 原始點＋摘要與區間 | 隱藏樣本數的長條圖 |
| 同一批人前後如何變化？ | 配對線圖、差值圖 | 把前後測畫成獨立兩組 |
| 兩個連續變項是否相關？ | 散佈圖＋合理的趨勢線 | 雙 Y 軸暗示關聯 |
| 數值隨時間如何改變？ | 時間序列或個體軌跡 | 類別順序不清的折線圖 |

圖表種類不是由軟體預設決定，而是由研究問題、資料型態和相依結構決定。

## 為什麼不建議用長條圖呈現連續資料？

Weissgerber 等人（2015）檢視 703 篇生理學研究，發現多數文章以長條圖或折線圖呈現連續結果，但很少顯示能讓讀者查看分布的點圖、箱形圖或直方圖。問題在於：許多完全不同的分布，可以產生相似的平均數與誤差棒。

研究樣本不大時，優先顯示每個原始資料點通常更誠實。讀者可以直接看到：

- 每組實際有多少人；
- 資料是否偏斜或有離群值；
- 組間有多少重疊；
- 結果是否由少數觀察驅動。

## SD、SE 與 CI 不能互換

- **標準差（SD）**描述樣本中個體數值的分散程度。
- **標準誤（SE）**描述平均數估計的抽樣精確度，通常為 `SD / √n`。
- **信賴區間（CI）**呈現與資料及模型相容的參數範圍。

圖說必須明確寫出誤差棒是哪一種。只寫「mean ± error」沒有解釋價值。若要讓讀者理解個體差異，不能用很窄的 SE 取代原始點或 SD。

## 前後測一定要讓「同一個人」被看見

假設運動介入前後的平均認知分數都有提升，至少可能存在三種情況：

1. 幾乎每位受試者都小幅進步；
2. 少數人進步很多，多數人沒有變化；
3. 有人進步、有人退步，平均後剛好呈現上升。

兩根長條無法區分這三種模式。配對線圖或直接畫出每個人的 `post − pre` 差值，才能呈現變化的一致性與異質性。

## 圖表也可能誤導

製圖時應檢查：

- 座標軸是否被截斷到誇大差異；
- 類別排序是否有明確理由；
- 顏色是否為唯一的辨識方式；
- 點太多時是否嚴重重疊；
- 趨勢線是否掩蓋非線性或群聚；
- 是否同時呈現樣本數、單位與不確定性；
- 圖說是否能單獨說明研究設計。

## 我的選圖順序

1. 先畫原始資料與每組樣本數。
2. 再依研究設計加入配對線、分布或時間結構。
3. 加上有明確定義的摘要值與區間。
4. 檢查圖形是否與模型分析的是同一個量。
5. 最後才調整顏色、字體與版面。

科學圖表的主要任務是暴露資料結構，而非壓縮成最容易閱讀的單一摘要。有效的圖形應讓讀者辨認變項尺度、樣本量、分布、相依性、估計值與不確定性，並與統計模型的分析單位一致。

## 圖形必須對應研究設計

獨立組、配對資料、重複量測與巢狀資料即使共享相同平均數，也需要不同的視覺編碼：

| 設計 | 至少要呈現 | 推薦圖形 |
|---|---|---|
| 單一連續結果 | 分布、樣本數與異常點 | jittered dot plot、ECDF、histogram |
| 兩個獨立組 | 各組原始點與估計差異 | dot plot＋difference estimate／CI |
| 配對前後測 | 個體對應與差值分布 | paired plot＋difference plot |
| 多時間點 | 個體軌跡及群體趨勢 | spaghetti plot＋model estimate |
| 連續變項關聯 | 聯合分布、非線性與群聚 | scatterplot＋診斷適當的 smoother |

圖形若忽略相依結構，會讓配對資料看起來像兩組獨立觀察，也可能將受試者內變化與受試者間差異混在一起。

## 不要讓摘要統計遮住分布

Weissgerber 等人（2015）指出，小樣本連續資料只以 mean ± SE 或 mean ± SD 呈現，會隱藏偏態、離群值、群聚與組間重疊。其系統性檢視納入 703 篇文章；這個數字描述的是特定時期與期刊範圍的觀察，不應被直接外推成所有學科的比例，但它充分示範了圖形慣例如何限制讀者查核結果。

專業呈現可採「原始資料＋估計量＋區間」的分層結構：

```text
第一層：每個獨立觀察或受試者軌跡
第二層：與研究問題對應的摘要或模型估計
第三層：信賴區間或其他明確定義的不確定性
```

若資料點不是獨立觀察，例如同一受試者有多個 trial，不能把所有 trial 畫成彷彿樣本數大幅增加。圖形與模型都必須清楚區分 participant-level 與 trial-level 資訊。

## SD、SE 與 CI 的不同角色

SD 描述觀察值離散程度；SE 是估計量在重複抽樣下的標準差；CI 則由估計量、標準誤、臨界值與模型假設構成。三者回答不同問題：

```text
SD：受試者之間有多不同？
SE：這次平均數估計有多精確？
CI：哪些母體參數值與資料及模型較相容？
```

誤差棒的圖說應寫明 SD、SE 或 CI、區間水準、分析單位及樣本數。重複量測設計若呈現 within-subject error bar，也必須說明計算方法，不能讓讀者誤認為一般組間 CI。

## 視覺化是模型診斷的一部分

建模前應利用圖形檢查：

- response distribution 與可能的 floor／ceiling effect；
- 組間變異是否差異明顯；
- 線性與同方差假設是否合理；
- 少數點是否具有高 leverage 或 influence；
- 重複量測軌跡是否呈現不同斜率；
- 缺失是否集中於特定組別或時間點。

模型完成後，再畫 observed values、fitted values、residuals 與 uncertainty。探索圖與正式結果圖可以不同，但兩者的資料處理規則都應可重現。

## 一個可重現的製圖範例

以下使用虛構資料示範配對圖；程式不包含任何真實研究數值：

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.lineplot(
    data=df,
    x="time",
    y="cognitive_score",
    units="participant_id",
    estimator=None,
    color="#9aa6b2",
    alpha=0.45
)
sns.pointplot(
    data=df,
    x="time",
    y="cognitive_score",
    errorbar=("ci", 95),
    color="#163a5f"
)
plt.ylabel("Cognitive score (specified scale)")
plt.xlabel("Assessment time")
```

實際研究仍需確認 point estimate、CI 的估計方法與主要統計模型一致，並在圖說中報告分析 N、排除與單位。

## 發布前圖表檢查

1. 原始點或分布是否可見？若不可見，理由是什麼？
2. 圖形是否正確表達獨立、配對或巢狀結構？
3. SD、SE、CI 與模型區間是否清楚命名？
4. 樣本數是否指獨立分析單位，而非重複資料列數？
5. 軸、單位、缺失、排除及轉換是否完整？
6. 不依賴顏色時是否仍可辨識？
7. 圖形產生程式與輸入資料版本是否保存？
