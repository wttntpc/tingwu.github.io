# EEG 學習地圖：從神經生理、設備到可重現分析

EEG 是頭皮電位隨時間變化的量測。它的時間解析度高，但訊號微弱，會受到眼動、肌電、電極接觸、參考方式與環境雜訊影響。真正理解 EEG，要把生理來源、設備、實驗設計、前處理與統計分析一起學。

## 建議的五級路徑

1. **100 生理**：膜電位、突觸後電位、群體神經活動、體積傳導與頭皮電位。
2. **200 設備**：電極、導電介面、阻抗、參考電極、放大器、ADC、取樣率與觸發器。
3. **300 取得**：10–20 系統、實驗時序、事件標記、受試者準備與原始資料備份。
4. **400 分析**：檢查原始波形、濾波、壞道、重參考、ICA、分段、基線、ERP、頻譜與時頻分析。
5. **500 推論**：品質控制、統計模型、多重比較、可重現程式與透明報告。

## 複習檢核

對每一個處理步驟回答：「它改變了什麼？依據是什麼？可能刪掉真正訊號嗎？如何用前後圖與數量報告？」如果只記得按鈕位置，還不能算理解分析。

## 從生成模型到統計模型

EEG 分析可分成五個相依層：神經電流源、頭部體積傳導、電極與放大器量測、數位訊號處理、統計推論。後一層不能修復前一層未記錄或設計錯誤的資訊，因此研究規劃必須先於前處理。

| 層級 | 必學問題 | QC 產出 |
|---|---|---|
| 生理／物理 | 訊號如何生成並傳到頭皮？ | 對來源與定位限制的說明 |
| 硬體 | 動態範圍、雜訊、共模抑制、同步是否足夠？ | 設備、位置、阻抗與事件紀錄 |
| 取得 | 作業、試次與比較條件能否辨識目標效應？ | 原始資料唯讀備份與 metadata |
| 處理 | 每一步的假設、參數與副作用為何？ | 排除數、前後圖、參數與版本 |
| 推論 | 分析單位、搜尋空間與不確定性為何？ | 效果估計、多重比較與敏感度分析 |

## 建議的深化順序

先掌握連續資料與事件資料的結構，再學 ERP；之後進入 Welch PSD、FFT、時頻與小波，最後才處理來源定位、連結性、跨頻耦合及 HHSA。每個進階方法都要先用模擬訊號驗證，再用真實資料檢查邊界效應、偽影與參數敏感度。
