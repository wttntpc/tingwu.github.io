# 運動生理學學習地圖：從急性反應到運動處方

運動生理學要回答兩個問題：一次運動時身體如何維持工作，以及反覆訓練後身體為什麼會適應。學習時不要把能量系統、肌肉、呼吸與循環拆成互不相關的章節；它們共同決定氧氣輸送、能量供應、疲勞與恢復。

## 建議的五級路徑

1. **100 基礎**：恆定性、ATP、三大能量系統、肌肉收縮、心輸出量與氣體交換。
2. **200 機制**：運動強度上升時，神經、心血管、呼吸、內分泌與體溫如何協調。
3. **300 量測**：心率、血壓、血乳酸、RPE、VO₂、通氣閾值、肌力與功率。
4. **400 分析**：急性反應、慢性適應、測量誤差、個體內變化與組間差異。
5. **500 應用**：依目標、風險、體適能與恢復狀態設計 FITT-VP 運動處方。

## 如何複習

選一個情境，例如「從休息跑到高強度」，依序畫出神經驅動、能量需求、氧氣輸送、乳酸、體溫與主觀用力的變化。再比較一次運動的反應與數週訓練後的適應，避免把兩者混為一談。

> 運動處方不是只套用百分比。測量方法、疾病風險、用藥、環境與個別反應都會影響強度判定，涉及臨床情境時應依專業評估與正式指引。

# 運動生理學學習地圖：從急性反應到運動處方

## 知識架構

本主線以「需求—輸送—利用—調節—適應」組織內容。急性運動的心血管調節涉及中央命令、活動肌肉反射與壓力感受器等機制；反覆訓練則引起器官、組織與分子層級的重塑。兩者應以不同時間尺度與研究設計處理。

| 層級 | 內容 | 研究連結 |
|---|---|---|
| 100 | 生物能量、肌肉、心肺與神經內分泌基礎 | 定義變項與單位 |
| 200 | 強度、時間、模式造成的急性整合反應 | 建立機制假說 |
| 300 | CPET、閾值、乳酸、肌力與穿戴式量測 | 評估效度、信度與誤差 |
| 400 | 縱向適應、疲勞恢復、反應異質性 | 混合模型與重複量測 |
| 500 | FITT-VP、風險分層與進階處方 | 由證據轉為可監測介入 |

## 學習產出

每個系統都整理成「刺激 → 感受器／訊號 → 調節器 → 效應器 → 可量測結果」。每一種測量再記錄校正、取樣條件、最小可偵測變化與生理意義。進入處方前，必須能區分相對強度、絕對強度、峰值百分比與閾值導向強度的假設及限制。
